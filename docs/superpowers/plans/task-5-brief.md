Read the design, common plan and Task 2's final tags/receipt format. Work solely with disposable repos containing generated data. Review actual Restic arguments before testing any destructive path. The private build is for the existing source/server pair.

**Deliverable.** The Backup Server dashboard shows free space, the last health check and an action to check repositories now. Its retention panel starts at “Keep all backups”. The user can preview an explicit keep policy, see eligible dates/folders and protected reasons, then confirm a particular preview. No background deletion.

**Interfaces.** Worker-only actions `StorageStatus`, `CheckStorage`, `PreviewRetention` (policy `KeepAll` or `KeepLatestPerFolder`, N >= 1), `ApplyRetention` (opaque server-issued PreviewId plus an explicit confirmation field). Return bounded preview pages or an explicit safe maximum with an actionable message, scoped counts/reasons and UTC check times. Store only nonsecret local policy, immutable preview fingerprint, exact candidate IDs and operation status under the engine owner root. Persistence of a chosen policy must never imply automatic execution.
