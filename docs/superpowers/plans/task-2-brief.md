**Deliverable.** A first-time pair can choose folder backups, prepare the server without video software, complete a verified ordinary sample and watch a manually selected folder reach “Backed up”. Existing media installations and their returned versions still work.

**Interfaces.** Use `BackupMode` values `Folder` and `Media` in setup, prepared/settings records and each newly queued item. The source mode is the requested behavior; the server mode describes capability. Existing v1 settings, prepared records, pairing requests and queued items lacking a mode imply Media. Brand-new setup explicitly defaults to Folder. Keep the existing `Invoke-NetCrateBackup` media call/return contract for its direct callers. Inside Workflow split the ordinary originals operation from media request publication. Add `Get-NetCrateBackupPath($Settings,[string]$Path,[string]$BackupMode)` to Configuration. Queue success contract for later tasks is `SnapshotId` (full 64 hex), `BackupCompletedUtc` (UTC ISO), `BackupMode`, `Project` (canonical path), `MediaState` (Off/Pending/Ready/NeedsAttention) and a durable job ID. Keep existing queue members readable. Use a new originals snapshot tag to distinguish positively marked Folder images from legacy media before retention.
